## Mi forma de trabajar

**Estandarización antes que improvisación.** Prefiero las convenciones claras, los componentes reutilizables y el código predecible. Que una solución funcione es importante; que también pueda entenderse y mantenerse, mucho más.

**IA como herramienta, no como piloto automático.** La aprovecho cuando aporta valor a una tarea específica, pero las decisiones técnicas y la revisión del resultado siguen siendo parte del trabajo.

**Automatización por curiosidad.** Si una tarea se repite, seguramente voy a pensar en cómo automatizarla.
